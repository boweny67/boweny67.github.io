01 / System Instance

具体系统界定
Arm-Rehab Mixed Assist System

作业 1–3 的通用对象是「机器增强的人机混合神经系统」；本作业把它落到一个可描述、可验证的整机实例：面向脑卒中后上肢运动功能障碍患者的混合辅助训练系统。生物通道保留患者残存的神经控制与本体感觉，人工通道由肌电采集、边缘决策、外骨骼/电刺激执行与触觉反馈构成，两路在训练任务中并行融合。

1.1

系统边界与组成

感知端

肌电与体征采集

臂环干/湿电极采集表面肌电，配合 IMU 关节角度、皮温与心率；识别患者运动意图与发力水平，信号质量实时自检。

决策端

边缘混合决策

本地完成意图分类、置信度评估与生物意图—机器建议仲裁；反射级闭环不依赖云端，模型更新与日志回传走非实时通道。

执行端

辅助出力与反馈

上肢外骨骼提供助力力矩，功能电刺激补偿肌肉收缩，触觉/力反馈回传接触与阻力；独立安全监护旁路并行监视越界。

1.2

与前序作业的衔接

本实例沿用作业 3 的双轨架构与 STPA 安全结论：意图识别端到端延迟 ≤200 ms，安全保护响应 ≤50 ms，单点失效默认回到无增强状态；本作业不再重复需求条目与控制框图，而是聚焦「它在哪些场景里、按什么条件运行、典型回合怎么走、会冒出哪些风险场景」。

02 / Scenario Layering

场景分层
From Mission Environment to Interaction Turn

由粗到细分四层：上层约束下层的目标与边界，下层是上层目标在具体环境中的落点。

S1 使命层 康复目标与社会环境 功能恢复生活回归医疗体系
↓
S2 环境层 运行场所与物理条件 康复科诊室社区康复站家庭居所
↓
S3 任务层 训练与代偿任务场景 评估测量被动助动主动辅助抗阻训练日常代偿
↓
S4 交互层 单次训练回合内的人机交互 佩戴自检意图采集辅助出力反馈回采记录结束
2.1

各层含义

S1 · 使命层

定义系统存在的目的：改善患者上肢运动功能、提高日常生活独立性，并对接康复医疗流程与家庭支持环境。该层决定后面所有场景的成功判据。

S2 · 环境层

系统被使用的物理与社会场所：康复科诊室有治疗师在场，社区站有指导员，家庭居所为无人或家属在场的自主训练环境，三者的监督强度与冗余条件不同。

S3 · 任务层

患者在各环境中要完成的任务类型：功能评估、被动关节活动、主动辅助抓握/伸展、抗阻强化，以及进食、取物等生活动作代偿。

S4 · 交互层

把一次任务拆成可观察的人机回合：从佩戴与自检开始，到意图采集、辅助出力、反馈回采，再到数据记录与安全退出，是风险最容易定位的一层。

03 / Scenario Elements

各层场景要素
Who · What · Where · Information

对每一层从环境、人员、系统、任务与信息五个维度梳理要素，作为后面设定运行设计条件和识别风险场景的依据。

场景层环境要素人员要素系统要素任务与信息要素
S1 使命层 康复政策、医疗资源、家庭与社会预期 患者、家属、治疗师、医师、医保与管理方 混合辅助训练系统及其远期功能定位 功能恢复目标、独立性指标、长期随访记录
S2 环境层 诊室/客厅/社区空间、桌椅与支撑、照明、地面、温湿度、网络条件 在场监督人员、旁观者、可求助距离 设备摆放、穿戴位置、供电与通信链路 环境约束记录、场地安全检查结果
S3 任务层 任务台面、目标物体、阻力来源、训练时段与时长 患者肌力与耐受力、治疗师处方、辅助等级 感知阵列、决策策略、执行通道、监护旁路 任务类型、目标动作、完成度与训练负荷
S4 交互层 单回合内的设备状态、即时体位与接触关系 患者瞬时意图、疲劳与疼痛反应；监督者介入时机 采样、意图分类、仲裁、助力/刺激输出、反馈回采 肌电/角度/力反馈流、置信度、告警与操作日志

04 / Operational Design Conditions

运行设计条件
Operational Design Domain · System · Operator

圈定系统被设计为可正常运行的边界：在什么范围、处于什么系统状态、面对什么人员状态时，训练才允许开始与持续。

4.1

运行设计范围（ODR）

适用人群
  • 成年脑卒中后单侧上肢偏瘫，认知可配合指令
  • 无电极接触部位皮肤破损、无急性关节损伤
  • 血压、心率处于医师评估允许训练的区间
场地与设备
  • 平整防滑地面、稳固座椅、周边无尖锐障碍
  • 电极阻抗合格、传感器校准在有效期内
  • 电量满足本次训练时长，通信链路冗余有效
性能边界
  • 助力力矩、关节角度与速度限在硬件安全限幅内
  • 意图识别延迟 ≤200 ms，保护响应 ≤50 ms
  • 单次训练 ≤30 min，超出即提示休息与降载
4.2

系统状态

状态进入条件系统行为
自检待机佩戴完成、上电检查电极阻抗、电量、传感器与链路；未通过不进入训练
评估测量自检通过、治疗师启动评估采集被动活动度、肌力基线与信号质量，不输出主动助力
被动助动患者放松、治疗师设定轨迹外骨骼带动肢体完成关节活动，患者不发力
主动辅助识别到主动意图且置信度达标在患者发力基础上补足缺口力矩，主导权保留在人体
抗阻训练治疗师处方允许、肌力达标按设定阻力提供对抗负荷，记录出力曲线
告警降级信号异常、体征越界、低电或温升越限提示 → 限制增强 → 强制停机递进响应，等待人工确认
故障安全主链路失效、双通道丢失或看门狗复位默认回无增强状态，执行器保持安全位姿并上报故障码
4.3

人员状态

角色正常状态要求异常信号（暂停或退出）
患者警觉可配合，疲劳度低，无明显疼痛或痉挛，理解本次动作要求烦躁、嗜睡、疼痛评分升高、肌肉痉挛、出汗致电极滑脱
治疗师 / 指导员掌握处方与限幅，在场观察动作与体征，可随时接管或停机离岗、无法判断动作质量、对告警未及时响应
家属（居家）了解急停位置与协助事项，不擅自调整阈值或模式越权操作、遮挡急停、在患者不适时仍继续训练

05 · Typical Scenario

典型场景详述
Home-Based Active-Assisted Grasp Training

选取居家环境下的「主动辅助上肢抓握训练」作为典型回合，按时间顺序展开。

场景前提
  • 患者：58 岁，右侧偏瘫约 3 个月，Brunnstrom Ⅳ 期，认知与配合度良好
  • 环境：家中客厅，稳固座椅与训练桌，日间，地面干燥无障碍
  • 人员：家属在旁；治疗师经上次评估给出辅助等级与限幅，可远程查看记录
  • 设备：臂环与外骨骼佩戴到位，电极阻抗合格，电量与链路正常
成功判据
  • 完成设定次数的抓握—放回动作，动作轨迹平稳无明显抖动
  • 助力随患者发力动态增减，未出现过冲、牵拉或痉挛
  • 全程体征与信号在限幅内，训练记录完整可回放
  • 结束后执行器退回安全位姿，患者无新增不适
5.1

回合动作流

佩戴与自检

患者就座，家属协助固定臂环与外骨骼；系统自检电极阻抗、电量、IMU 与通信链路，通过后进入待机。

系统状态：自检待机 → 就绪

意图采集与确认

患者尝试抬手抓握，系统采集肌电与关节角度，输出动作意图与置信度；低于阈值时只给提示，不输出主动助力。

关键指标：识别延迟 ≤200 ms

混合仲裁与辅助出力

决策单元比较生物意图、机器建议与安全约束，仲裁后外骨骼补足缺口力矩，必要时叠加电刺激；触觉反馈回传接触与阻力。

通道：生物通道 + 人工通道双轨并行

反馈回采与持续监视

执行结果经本体感觉、IMU 与力反馈回采，与目标轨迹比对；安全监护旁路并行监视力矩、角度、体征与信号质量。

监护不串联主链路，失效不拖垮训练

回合结束与安全退出

达到设定次数或患者疲劳/不适即停止；执行器退回安全位姿，系统生成本次训练记录，可导出供治疗师远程复盘。

退出条件：完成目标 / 主动停机 / 告警降级 / 故障安全

风险场景列表
Hazard Scenario Register

围绕典型回合，列出边界被突破时可能出现的风险场景、诱因、后果与缓解措施；缓解措施与作业 3 派生的安全需求（SSR）对应。

编号触发场景 / 诱因可能后果风险等级缓解措施 · 关联安全需求
RS-1 肌力偏弱时意图被高估，助力力矩超过关节承受范围 关节牵拉、软组织损伤或疼痛加重 高 硬件限幅 + 越限切断；低置信度转辅助/原生（SSR-1、SSR-2）
RS-2 出汗、电极滑动或肌电伪迹导致意图识别漂移 输出非意图动作，动作方向或幅度错误 高 信号质量门控；双通道冗余与毫秒级切换（SSR-2、SSR-11）
RS-3 反馈缺失或超时，系统仍按有反馈状态继续出力 动作过冲、振荡，偏离目标轨迹 中 反馈超时冻结输出，保持安全位姿（SSR-3）
RS-4 监护旁路失效且未被发现，越界后无保护介入 危险输出持续到主链路察觉，伤害扩大 高 监护周期自检、失效显性告警，独立于主链路（SSR-4）
RS-5 低电量或温升越限，未及时降载与提示 训练中途失效，支撑不足导致跌倒或脱手 中 分级降载并保留无源机械支撑（SSR-9）
RS-6 未授权人员修改阈值或控制模式 人工否决权被绕过，增强等级超出处方 中 变更分级授权并留痕，自动模式不得绕过人工确认（SSR-10）
RS-7 急停请求被软件拦截或延迟执行 紧急情况下无法立刻切断增强输出 高 物理急停硬线直达切断回路，不经软件与无线链路（SSR-6）
RS-8 居家环境存在障碍物或座椅不稳，训练中失去平衡 跌倒、碰撞，连带损伤患侧与健侧 低 ODR 场地检查清单；无源支撑与跌倒保护设计（SSR-9、SSR-12）
6.1

风险场景与前序分析的衔接

上述 RS 条目可回溯到作业 3 的危险（H-1～H-7）与不安全控制动作（UCA-1～12）：RS-1/2 对应错误意图与越界出力，RS-3 对应反馈失控，RS-4/7 对应监护失效与人在环否决被延迟，RS-5/8 对应断电断链兜底；本作业不重复推导过程，只在具体场景中核对这些风险是否可被现有安全需求覆盖。
