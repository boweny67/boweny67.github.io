01 / SyRS

系统需求规格书
System Requirement Specification

把作业 2 的 StRS 条目上升为系统级需求，并补齐可用性、运行、模式状态、物理与法规等条目；依据 ISO/IEC/IEEE 29148:2018 的 SyRS 大纲组织。

1.1

目的、范围与系统概述

目的：在维持人体生命稳态的前提下，闭环完成「感知—决策—行动」神经活动；为神经功能受损人群提供感知/运动代偿，为特殊作业环境下的健康人员扩展能力。所有增强功能均可启停、可降级，使用者保留最高否决权。

系统包含：人体神经信号与体征采集前端、外部多模态传感阵列、边缘混合决策单元、机器执行单元、能源管理单元、旁路式安全监护子系统、参数配置与日志接口。

系统不包含：临床诊断与治疗决策（由医师在系统外完成）、云端长期健康档案管理、器件级 BOM 与机械结构详细图纸。

系统概述：系统由生物通道与人工通道双轨并行构成，在感知、决策、执行三段融合。信号流、控制结构与旁路安全机制见第 2 章初始架构与第 3 章控制框图，本节不再重复运行时序描述。

其他需求

可用性

易用与可退出

穿脱简便；响应随意图自然跟随；应急退出途径显著；告警同时具备视觉与触觉通道；接触部位材料可清洁、可更换。

整机约 2.43 kg、典型工作功耗约 29.0 W（不含启动峰值）；模块快拆可替换；电磁兼容，材料生物相容，耐受出汗与消毒。

信息 / 法规 / 保障

留痕与可维护

日志加密、分级访问、可回放；符合 ISO 10993、IEC 60601 与伦理、个保要求；模块可独立替换测试，支持校准与预测性维护。

2.3

通道、计算分区与权衡

双轨并行：生物与人工通道在感知、决策、执行三段并列；任一通道降级，另一通道仍维持基础功能。增强是叠加项，不是替代项。

计算分区：反射级闭环（滤波、意图分类、安全规则、关节控制）在本地边缘单元；云端只承担日志汇总、模型更新、策略下发与远程复盘，不进入实时控制链路。

权衡轴方向代价
侵入性 ↔ 信号质量无创头环 → 肌电臂环 → 植入阵列侵入性越高，通道数、带宽、延迟越好，手术与感染风险上升
实时性 ↔ 算力位置本地 MCU → 边缘 NPU → 云端越往云端延迟越高，反射动作不能放云端
续航 ↔ 负重小电池包 → 可换大包 → 采集+小包电量增加意味着重量与体积增加
出力 ↔ 功耗重量触觉反馈 → 电刺激 → 外骨骼关节出力越大，功耗、重量与机械风险越高

03 / Control Diagram

系统控制框图
Perception–Decision–Action Closed Loop

前向链路、反馈回路、旁路安全监护与人在环干预，画在同一张控制结构里。

前向控制链路 反馈回路 旁路安全监护 人在环干预

控制回路：前向链路为环境 → 双轨感知 → 采集预处理 → 混合决策 → 双路执行 → 人体/环境；反馈链路把本体感觉、肌电、关节角度与力反馈回采，前馈通道做意图预测与延迟补偿。

旁路安全：监护子系统不串联在主链路等待执行，而是并行监视采集、决策、执行三段；它失效不拖垮主链路，主链路失效它仍能独立切断输出。物理急停以硬线直达执行切断回路，不经过决策软件栈。

运行时序：并行采样并对齐时间基准 → 降噪/伪迹去除/特征提取 → 意图分类输出动作与置信度 → 冲突仲裁比较生物意图、机器建议与安全约束 → 双路分送执行 → 执行结果反馈回采比对 → 监护全程并行比对阈值 → 全过程写入日志。

模式与急停链路：正常切换须先确认输出处于安全位姿再换模式；告警降级由监护触发，先限制增强、未恢复则强制停机；急停硬线切断执行输出，执行器保持安全位姿并锁定故障安全状态，检修后方可复位。

04 / Safety Analysis

安全需求与安全架构
STPA · System-Theoretic Process Analysis

基于初始控制结构，从损失与危险出发，识别不安全控制动作，反向派生安全约束并落实到架构组件。

4.1

损失（Loss）

编号损失
L-1人身伤害：电击、烫伤、机械碰撞、过度拉伸或冲击致伤
L-2生命体征失稳：呼吸、心率、体温等越出正常区间
L-3失控或误动作：输出非意图动作，或出力/角度失控
L-4神经与组织不可逆损伤：过流刺激、长期压迫、电极感染
L-5神经信号与健康数据泄露、滥用
L-6意外丧失行动能力：断电、断链后失去支撑导致跌倒
4.2

系统危险（Hazard）

编号危险状态关联损失
H-1执行器输出超出人体安全边界（力矩、角度、电流、温度）L-1, L-3, L-4
H-2控制器基于错误意图或低置信度识别发出动作指令L-3, L-1
H-3反馈缺失、超时或失真，环路滞后、过冲或振荡L-3, L-6
H-4监护失效且未被发现，越界后无保护介入L-1, L-2, L-3
H-5电气失效：漏电、过流刺激、绝缘破坏L-1, L-4
H-6权限失控或数据未加密、未授权访问L-5
H-7断电、断链或模块失效后无安全兜底，输出保持危险状态L-6, L-1
4.3

不安全控制动作（UCA）

四类：① 未提供应提供的动作；② 提供了不安全动作；③ 时序/顺序错误；④ 停止过早或持续过久。

编号控制器不安全情形类别派生约束
UCA-1决策识别置信度不足仍输出主动增强② 提供不当动作低于阈值转辅助/原生
UCA-2执行力矩/角度超出人体安全限幅② 提供不当动作硬件限幅，越限切断
UCA-3执行刺激电流/脉宽超过组织安全上限② 提供不当动作硬件电流钳位 + 电气隔离
UCA-4决策意图未确认抢先输出，双路冲突未仲裁③ 时序/顺序错误指令须经仲裁确认
UCA-5执行动作完成后出力仍持续施加④ 持续过久完成判定/超时自动卸载
UCA-6监护越界未识别、未告警、未切断① 应提供未提供监护独立自检，失效显性告警
UCA-7决策/执行反馈丢失超时仍按有反馈状态控制③ 时序错误反馈超时冻结输出
UCA-8能源低电量/温升越限未降载或未提示① 应提供未提供分级降载，保留安全位姿
UCA-9决策/交互未授权修改阈值或模式② 提供不当动作变更分级授权并留痕
UCA-10控制故障时未退回原生，停在增强状态④ 停止过早/未执行单点失效默认无增强
UCA-11人在环退出/急停请求被拒绝或延迟执行① 应提供未提供人工否决权最高，硬线直达
UCA-12信息未加密或越权上传健康数据② 提供不当动作加密存储、授权、留痕

4.6

安全架构

分层防护

四层结构

监督层（人在环）→ 决策层（本地边缘）→ 执行层（带硬件保护）→ 独立旁路安全层。

冗余与失效

失效默认安全

双链路物理独立；fail-safe；分级降级：提示 → 限制增强 → 强制停机 → 纯原生；断电时无源机械结构先保证人不摔倒。

共因隔离

独立不共用

监护不与主链路共用供电、传感器、时钟与软件，避免双重保护在共因失效下同时失效。

架构对应：独立旁路监护 ← SSR-4/12；硬件限幅 + 硬线急停 ← SSR-1/5/6；冗余通道 + fail-safe ← SSR-7/11；分级降级与无源支撑 ← SSR-9；授权加密留痕 ← SSR-8/10。
