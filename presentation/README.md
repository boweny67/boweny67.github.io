# 小组系统工程作业 · 串讲演示稿

四份作业的网页 PPT 串讲，实例为「上肢康复混合辅助训练系统（Arm-Rehab）」。

## 本地预览

任选一种：

```bash
# 在本目录下
python3 -m http.server 8770
# 浏览器打开 http://localhost:8770/index.html
```

或直接用浏览器打开 `index.html`（相对路径引用，无需构建）。

## 操作

- `←` / `→`（或空格）翻页，`Home` / `End` 到首页 / 末页，`F` 或右上角按钮全屏
- 地址栏 `#slide-N` 可直接定位到第 N 页，例如 `index.html#slide-12`
- 每页动画在页面内部播放：点动画下方圆形播放键手动播放 / 暂停 / 结束后重播；无音频，不弹出外部视频播放器
- 共 19 页，按正常讲述语速约 15 分钟讲完

## 页面结构
