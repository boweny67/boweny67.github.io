01 / 系统对象

Arm-Rehab：为偏瘫上肢做混合辅助

  • 服务对象：脑卒中后单侧上肢偏瘫、认知可配合指令的康复期患者。
  • 生物通道：保留患者残存的神经控制与本体感觉；人工通道：肌电采集、边缘决策、外骨骼/电刺激执行、触觉反馈，两路并行融合。
  • 定位边界：辅助是叠加项，不是替代项；患者保留最高否决权，所有辅助均可启停、可降级。
  • 系统不含：临床诊断与治疗决策，由医师在系统外完成。

03 / 作业 2 · BRS 业务口径

业务使命、约束与相关方协同

基础业务

守住生命底线：训练全程保障心率、血压、呼吸、体温等体征稳定，是其余辅助功能的前置条件。

原生业务

延续残存感知—行动闭环：保护患者残存通路本身，而不是绕开它直接控制肢体。

增强业务

代偿上肢功能缺失：补足抓握、伸展的运动缺口，配合电刺激与触觉反馈恢复自主活动。

业务约束 BC-1~4安全优先级最高 · 人拥有最高否决权 · 医用相容与 EMC 规范 · 不破坏原有自主调节
业务性能 BP-1~3生命指标稳定可控 · 闭环延迟可接受 · 辅助可启停、可降级

ConOps 三方协同：患者在诊室、社区站或居家日常使用，治疗师设定安全边界与参数，技师负责校准与故障处理；辅助等级随康复阶段调整。

03 / 作业 2 · 运行概念与验收条目

一次训练回合，信号从哪来、谁兜底

  • StRS 条目：功能需求 FR-1~8，以及性能 PR、接口 IR、安全 SR、设计约束 DR。
  • 每条需求都能回溯到业务使命、业务约束或某一类相关方诉求。
  • 旁路安全：监护并行监视，不串在主链路里等待执行；监护失效不拖垮主链路，主链路失效时仍能切断输出。

04 / 作业 3 · 控制结构

前向、反馈，与旁路监护

  • 前向链路：环境 → 双轨感知 → 采集预处理 → 混合决策 → 双路执行 → 人体与环境。
  • 反馈链路：本体感觉、IMU 与力反馈回采到采集端，预测补偿降低相位滞后。
  • 旁路安全：监护并行监视采集、决策、执行三段，越界时限幅、切断或降级。
  • 人在环：物理急停以硬线直达切断回路，不经过决策软件栈。

04 / 作业 3 · STPA 安全分析

从损失，反推安全需求

  • 分析链：确定损失 → 系统危险 → 不安全控制动作（UCA）→ 致因场景 → 反向派生安全需求。
  • UCA 四类：未提供应提供的动作、提供了不安全动作、时序/顺序错误、停止过早或持续过久。
  • 分层防护：监督人 → 本地决策 → 带硬件保护的执行层 → 独立旁路安全层；单点失效默认回无增强状态。

05 / 作业 4 · 场景与风险

系统在什么情况下、由谁、做什么

场景不是一张笼统的使用画面：由使命到交互逐层收敛；运行设计条件圈定允许正常工作的边界；风险场景从偏离路径中识别，并回挂作业 3 的危险、UCA 与安全需求。

05 / 作业 4 · 场景分层与 ODC

四层场景，上层约束下层

  • S1 使命层康复目标、生活回归与医疗社会环境
  • S2 环境层康复科诊室 · 社区康复站 · 家庭居所
  • S3 任务层评估测量 · 被动助动 · 主动辅助 · 抗阻 · 日常代偿
  • S4 交互层单回合内的佩戴自检、意图采集、出力、回采、退出

运行设计条件（ODC）界定适用人群、场地设备与性能边界；超出范围时转入降级或故障安全，不继续按自动增强运行。

05 / 作业 4 · 典型场景详述

典型回合：居家主动辅助抓握训练

前提：58 岁、右侧偏瘫约 3 个月，Brunnstrom Ⅳ 期，认知配合；家中客厅、家属在旁。成功判据：抓握—放回轨迹平稳，助力随发力增减，全程体征与出力在限幅内，记录可回放。

风险场景 RS-1~8 分三类消化：ODC 内靠置信度门槛与限幅消化；能源、链路与退出路径靠降级兜底；监护独立性与权限审计由独立安全层承担，逐条回挂 SSR。
